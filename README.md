# Telegram Bot для управления встречами

## 🎯 О проекте

Telegram бот для управления встречами с современной модульной архитектурой. Бот позволяет создавать события, управлять участниками, обрабатывать платежи и администрировать клубные встречи.

## ⚡ Быстрый старт

### Требования

- Node.js 18+
- npm или yarn

### Установка

1. **Клонируйте репозиторий:**

```bash
git clone <repository-url>
cd telegram-bot
```

2. **Установите зависимости:**

```bash
npm install
```

3. **Настройте окружение:**

```bash
cp env.example .env
```

Отредактируйте файл `.env`:

```env
BOT_TOKEN=your_bot_token_here
NODE_ENV=development
DATABASE_PATH=database.sqlite
```

4. **Запустите бота:**

```bash
npm run dev
```

## 🏗️ Архитектура

### Слоистая архитектура

```
Controllers (UI) → Services (Business) → Repositories (Data) → Database
```

### Структура проекта

```
src/
├── types/           # Типы и интерфейсы
├── constants/       # Константы сообщений и кнопок
├── dto/            # Data Transfer Objects
├── services/       # Бизнес-логика
├── repositories/   # Работа с данными
├── controllers/    # Обработка команд
├── scenes/         # Telegram сцены (wizards)
├── utils/          # Вспомогательные функции
├── entities/       # Сущности базы данных
├── bot/            # Основной класс бота
└── index.ts        # Точка входа
```

### Применённые паттерны

- **Repository Pattern** - абстракция работы с данными
- **Service Layer** - бизнес-логика
- **DTO Pattern** - передача данных между слоями
- **Dependency Injection** - инверсия зависимостей

## 🗄️ База данных

Проект использует SQLite для локальной разработки с возможностью переключения на PostgreSQL для продакшена.

Автоматически создаются таблицы:

- `user` - пользователи
- `event` - события
- `event_participant` - участники событий
- `payment_details` - реквизиты для оплаты
- `club_info` - информация о клубе

## ⚙️ Конфигурация

### Переменные окружения

```env
# Основные настройки
BOT_TOKEN=your_telegram_bot_token
NODE_ENV=development|production

# База данных (SQLite)
DATABASE_PATH=database.sqlite

# Опционально: PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_USER=your_username
DB_PASS=your_password
DB_NAME=your_database

# Логирование
VERBOSE_LOGGING=true|false
```

### Администраторы

Измените список администраторов в файле `src/config.ts`:

```typescript
export const ADMINS = [
  '123456789', // Замените на реальные Telegram ID
  '987654321',
]
```

## 🛠️ Разработка

### Добавление новых функций

1. **Создайте Entity** (если нужно) в `src/entities/`
2. **Создайте Repository** в `src/repositories/`
3. **Создайте Service** в `src/services/`
4. **Создайте Controller** в `src/controllers/`
5. **Подключите к боту** в `src/bot/bot.ts`

### Структура контроллера

```typescript
export class MyController {
  constructor(private myService: MyService) {}

  async handleAction(ctx: BotContext): Promise<void> {
    // Логика обработки
  }
}
```
