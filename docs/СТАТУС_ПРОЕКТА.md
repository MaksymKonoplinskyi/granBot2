## 🚀 Инструкция по запуску

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка окружения

```bash
# Скопируйте env.example в .env
cp env.example .env

# Отредактируйте .env файл и установите ваш токен:
# BOT_TOKEN=your_real_bot_token_here
```

### 3. Запуск

```bash
# Рефакторенная версия
npm run dev

# Legacy версия
npm run dev:legacy
```
