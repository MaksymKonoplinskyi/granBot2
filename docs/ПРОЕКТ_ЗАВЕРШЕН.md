## 🚀 Готово к использованию

### Быстрый запуск:

```bash
# 1. Настройте .env файл
cp env.example .env
# Установите BOT_TOKEN

# 2. Запустите проект
npm run dev
```

### Доступные команды:

```bash
npm run dev         # Разработка
npm run build       # Сборка
npm start          # Продакшен
npm run dev:verbose # С логированием
npm run lint       # Проверка кода
npm test           # Тесты (в планах)
```
