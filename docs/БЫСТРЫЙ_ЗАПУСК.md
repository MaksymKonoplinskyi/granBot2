## 🏃‍♂️ Запуск за 3 шага

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка окружения

```bash
# Скопируйте env.example в .env
cp env.example .env

# Отредактируйте .env файл:
# BOT_TOKEN=your_bot_token_here
# DATABASE_URL=sqlite:./database.sqlite
```

**Важно:** Обязательно установите свой токен бота в файле `.env`!

### 3. Запуск

```bash
# Рефакторенная версия (рекомендуется)
npm run dev

# Или legacy версия (совместимость)
npm run dev:legacy
```

## 📁 Структура проекта (после рефакторинга)

```
src/
├── types/              # Типы и интерфейсы
├── constants/          # Константы и сообщения
├── dto/               # Data Transfer Objects
├── repositories/      # Слой данных
├── services/          # Бизнес-логика
├── utils/             # Утилиты
├── controllers/       # Контроллеры
├── bot/              # Главный бот
├── entities/         # TypeORM сущности
└── index.ts          # Точка входа
```

## 🔧 Доступные команды

```bash
# Разработка
npm run dev              # Рефакторенная версия
npm run dev:legacy       # Legacy версия
npm run dev:verbose      # С подробным логированием

# Производство
npm run build            # Сборка проекта
npm start               # Запуск сборки
npm run start:legacy    # Legacy сборка

# Проверка
npm run lint            # Проверка кода
```

## 🆘 Решение проблем

### Проблема с sqlite3

```bash

```

```bash

```

### Проблема с зависимостями

