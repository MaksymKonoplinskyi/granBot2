## 🎯 Различия между версиями

### Рефакторенная версия:

- Использует `src/index.ts` как точку входа
- Конфигурация БД встроена в `src/index.ts`
- Поддерживает SQLite и PostgreSQL
- Слоистая архитектура с DI

### Legacy версия:

- Использует `src/legacy-start.ts` как точку входа
- Конфигурация БД в `src/data-source.ts`
- Только PostgreSQL
- Монолитная архитектура

## 🚀 Запуск проекта

### Рефакторенная версия (рекомендуется):

```bash
npm run dev          # Разработка
npm run build        # Сборка
npm start           # Продакшен
```

### Legacy версия (обратная совместимость):

```bash
npm run dev:legacy   # Оригинальный бот
npm run start:legacy # Продакшен legacy
```
