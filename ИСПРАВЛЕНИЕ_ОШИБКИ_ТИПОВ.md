# Исправление ошибки типов данных в Entity классах

## 🐛 Проблема

При запуске рефакторенной версии бота возникала ошибка:

```
❌ Ошибка при запуске бота: DataTypeNotSupportedError: Data type "Object" in "User.firstName" is not supported by "sqlite" database.
```

## 🔍 Причина

TypeORM не смог правильно определить типы данных для SQLite базы данных. Поля с типом `string | null` интерпретировались как `Object`, что не поддерживается SQLite.

## ✅ Решение

Исправлены типы данных во всех Entity классах для совместимости с SQLite:

### 1. Entity User

```typescript
// До исправления
@Column({ nullable: true })
firstName!: string | null;

// После исправления
@Column({ type: 'text', nullable: true })
firstName!: string | null;
```

### 2. Entity Event

```typescript
// До исправления
@Column({ type: 'decimal', precision: 10, scale: 2, nullable: true })
fullPaymentAmount!: number | null;

// После исправления
@Column({ type: 'real', nullable: true })
fullPaymentAmount!: number | null;
```

### 3. Entity EventParticipant

```typescript
// До исправления
@Column({
  type: 'enum',
  enum: ParticipationStatus,
  default: ParticipationStatus.PENDING_PAYMENT
})
status!: ParticipationStatus;

// После исправления
@Column({
  type: 'text',
  default: ParticipationStatus.PENDING_PAYMENT
})
status!: ParticipationStatus;
```

## 📋 Все изменения

### User.ts

- `@Column()` → `@Column('integer')` для telegramId
- `@Column({ nullable: true })` → `@Column({ type: 'text', nullable: true })` для string полей
- `@Column({ default: false })` → `@Column({ type: 'boolean', default: false })` для boolean полей

### Event.ts

- `@Column()` → `@Column('text')` для title
- `@Column()` → `@Column('datetime')` для Date полей
- `@Column({ type: 'decimal', ... })` → `@Column({ type: 'real', ... })` для числовых полей
- `@Column({ type: 'timestamp', ... })` → `@Column({ type: 'datetime', ... })` для Date полей
- `@Column({ type: 'varchar', ... })` → `@Column({ type: 'text', ... })` для string полей

### EventParticipant.ts

- `@Column({ type: 'enum', ... })` → `@Column({ type: 'text', ... })` для enum полей
- `@Column('varchar', ...)` → `@Column({ type: 'text', ... })` для string полей
- `@Column('int', ...)` → `@Column({ type: 'integer', ... })` для number полей

### PaymentDetails.ts

- `@Column()` → `@Column('text')` для title

## 🎯 Типы данных для SQLite

| TypeScript тип     | SQLite тип | Декоратор             |
| ------------------ | ---------- | --------------------- |
| `string`           | `text`     | `@Column('text')`     |
| `number` (integer) | `integer`  | `@Column('integer')`  |
| `number` (float)   | `real`     | `@Column('real')`     |
| `boolean`          | `boolean`  | `@Column('boolean')`  |
| `Date`             | `datetime` | `@Column('datetime')` |
| `enum`             | `text`     | `@Column('text')`     |

## 📝 Примечания

- SQLite имеет ограниченный набор типов данных
- TypeORM требует явного указания типов для правильной работы
- Все изменения обратно совместимы с PostgreSQL
- Legacy версия продолжает работать без изменений
