### 3. **Типизация Entity и DTO**

**Проблема:**

- Несоответствие nullable типов между Entity и DTO
- `undefined` vs `null` в типах

**Решение:**

```typescript
// ДО (DTO)
description!: string        // undefined для необязательных полей
firstName?: string

// ПОСЛЕ (DTO)
description!: string | null // null для соответствия Entity
firstName?: string | null

// Entity
@Column({ nullable: true })
firstName!: string | null   // Явное указание null типа
```
